# YuanShen-UnlockerLite

> 一个轻量的解锁帧率和FOV的插件；主要用于轻量玩家和版本更新时部分插件不能使用时的替代；并修复了部分BUG

## 功能

- **解帧**，并修复了游戏内公告窗口异常卡顿的现象
  - 目标帧率可配；写 `0` 或负数表示不限帧（内部折算为 `999`），游戏内部硬上限是 1000，填更大也只按 1000 生效
  - **注意**,解决了至冬部分角色抽搐的问题;代价是不能在幽静危站开启实际上超过120的fps！
  - 可选：游戏窗口不在前台时把帧率压到 10，省后台占用；目标本身低于 10 时不抬高
- **FOV**，解决了部分游戏界面 FOV 异常、跳跃的问题
  - 目标视场角可配，有效范围 `[30, 179]`（引擎硬上限 179，填更大会被夹回去）
  - 映射规则：`(30, 目标值]` 区间内的值一律顶到目标值；`30` 及以下、或**高于目标值**的原样透传
    （高值那段留给瞄准、过场等游戏自己的拉远；目标值填 `30` 时整段退化为不改）
  - 呼出鼠标（Esc 菜单、背包、对话等）或切出游戏时，视场角会平滑恢复成游戏原生值，回到游戏再平滑切回目标值

## 使用

### 安装

用任意启动器 / DLL 注入器把 `YuanShen-UnlockerLite.dll` 注入游戏进程即可。

- 运行时读取的是**与 DLL 同目录**的 `Config.ini`
- 建议在游戏启动后尽早注入，hook 是注入时安装的

### 配置

改完 `Config.ini` 会自动热重载，不需要重启游戏。

| 段 | 类型 | 取值 | 说明 |
|---|---|---|---|
| `[General]` | — | — | 面板展示用的元信息 |
| `[Fps]` | bool | `1` / `0` | 帧率解锁开关 |
| `[TargetFps]` | int | 0 ~ 1000 | 目标帧率；`0` 或负数 = 不限帧（内部折算为 `999`） |
| `[FpsGetterClamp]` | bool | `1` / `0` | 把帧率 getter 的返回值钳到 120 以内；用于削弱帧率相关遥测 |
| `[FpsBackgroundLimit]` | bool | `1` / `0` | 游戏不在前台时把帧率压到 10；目标低于 10 时保持原值 |
| `[Fov]` | bool | `1` / `0` | 视场角解锁开关 |
| `[TargetFov]` | int | 30 ~ 179 | 目标视场角；`(30, 目标值]` 顶到目标值，30 及以下或高于目标值透传 |
| `[FovRecover]` | bool | `1` / `0` | 呼出鼠标或切出游戏时，平滑恢复成游戏原生视场角 |
